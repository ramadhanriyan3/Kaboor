# Kaboor - Flight Ticket Booking App

Kaboor is a user-friendly flight ticket booking application that simplifies the process of finding, comparing, and booking flights.

## Features
- **Search Flights**: Enter destination, date, and other preferences to search for flights.
- **Compare Prices**: View multiple airlines and compare ticket prices.
- **Book Tickets**: Securely book tickets and receive confirmation.
- **Responsive Design**: Optimized for both desktop and mobile devices.

## Technologies Used
- **Frontend**: Next.js, TailwindCSS
- **Backend**: (e.g., Express.js, Node.js)
- **State Management**: Redux Toolkit
- **Others**: Query-string for URL management

## Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/ramadhanriyan3/Kaboor.git
   ```
2. Navigate to the project directory:
   ```bash
   cd Kaboor
   ```
3. Install dependencies:
   ```bash
   npm install
   ```
4. Run the development server:
   ```bash
   npm run dev
   ```
5. Open [http://localhost:3000](http://localhost:3000) to view the app in the browser.
